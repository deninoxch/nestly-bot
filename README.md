# 🏠 Nestly — Telegram-бот мебельной компании
 
Учебный проект: полнофункциональный Telegram-бот для мебельной компании на **aiogram 3.x** с поддержкой каталога товаров, ролевой системы администраторов, интернационализации и B2B-заявок на сотрудничество.
 
## ✨ Возможности
 
### Для покупателей
- 📂 Навигация по каталогу мебели с вложенными категориями
- 🌍 Фильтрация товаров по стране производства (Россия / США)
- 📸 Карточки товаров с каруселью до 10 фотографий (через Telegram `file_id`)
- 🌐 Переключение языка интерфейса (Русский / English)
- 🤝 Подача заявки на B2B-сотрудничество
- 🛒 Кнопка заказа с прямым переходом к менеджеру
### Для администраторов
- 📁 Добавление категорий и товаров через пошаговый диалог (FSM)
- 🛠 Управление каталогом: скрытие/показ категорий и товаров, редактирование цены
- 📋 Просмотр и обработка заявок на сотрудничество (принять/отклонить)
- 🗂 История обработанных заявок с возможностью удаления
- 💬 Прямая связь с заявителем через Telegram
### Для суперадминистратора
- 👥 Назначение и снятие роли администратора у пользователей
- 🔐 Иерархия прав: `superadmin` жёстко привязан к `telegram_id` из конфига (поддержка нескольких ID)
## 🛠 Технологический стек
 
| Технология | Назначение |
|---|---|
| Python 3.11+ | Язык разработки |
| aiogram 3.x | Асинхронный Telegram Bot Framework |
| SQLAlchemy 2.x | ORM для работы с базой данных (async) |
| SQLite + aiosqlite | База данных |
| Alembic | Миграции базы данных |
| pydantic-settings | Типизированная конфигурация из `.env` |

## 🚀 Запуск проекта
 
### 1. Клонирование и окружение
 
```bash
git clone https://github.com/deninoxch/nestly-bot.git
cd nestly-bot
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
 
### 2. Настройка окружения
 
Создайте файл `.env` в корне проекта:
 
```env
BOT_TOKEN=токен_от_BotFather
SUPERADMIN_IDS=ваш_telegram_id,второй_id_через_запятую
DATABASE_URL=sqlite+aiosqlite:///nestly.db
DEBUG=True
COMPANY_CONTACT_USERNAME=(твой юз)
```
 
- `BOT_TOKEN` — получить у [@BotFather](https://t.me/BotFather)
- `SUPERADMIN_IDS` — узнать свой Telegram ID у [@userinfobot](https://t.me/userinfobot); можно указать несколько ID через запятую
### 3. Применение миграций
 
```bash
alembic upgrade head
```
 
### 4. Запуск бота
 
```bash
python -m bot.main
```
 
После первого сообщения `/start` от аккаунта с ID из `SUPERADMIN_IDS` пользователю автоматически присваивается роль суперадминистратора.
 
## 🔑 Роли и права
 
| Роль | Права |
|---|---|
| `user` | Просмотр каталога, подача заявок на сотрудничество |
| `admin` | + управление каталогом (добавление/скрытие/цена), обработка заявок |
| `superadmin` | + назначение/снятие роли `admin` у других пользователей |
 
## 📋 Команды бота
 
| Команда | Доступ | Описание |
|---|---|---|
| `/start` | все | Главное меню |
| `/language` | все | Смена языка интерфейса |
| `/admin_panel` | superadmin | Панель управления |
| `/add_category` | admin | Добавить категорию |
| `/add_product` | admin | Добавить товар |
 
## 🗄 Модель данных
 
- **User** — пользователи бота, их роль и язык интерфейса
- **Category** — категории мебели с поддержкой вложенности (`parent_id`)
- **Product** — товары с мультиязычными полями (RU/EN), страной и ценой
- **ProductPhoto** — фотографии товара (до 10 штук), хранятся через Telegram `file_id`
- **Application** — заявки на B2B-сотрудничество со статусом (`pending` / `accepted` / `rejected`)
## 📝 Архитектурные решения
 
- **Мультиязычность полей БД** реализована через отдельные колонки (`name_ru`, `name_en`) — простое и надёжное решение для двух языков
- **Роль суперадминистратора** дополнительно подстраховывается сверкой с `SUPERADMIN_IDS` из конфигурации при каждом входе — защита от потери доступа при сбоях в БД
- **Мягкое удаление** категорий и товаров через поле `is_active` — данные не теряются безвозвратно
- **Оплата не реализована умышленно** — бот работает по модели генерации заявок с последующей связью через менеджера, что типично для мебельного e-commerce, где условия (доставка, замеры) обсуждаются индивидуально
